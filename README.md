# Evento-Ficticio-em-HTML
Esta é uma atividade de desenvolvimento em HTML proposta pela professora Suzana Lustosa, em que o desafio é criar um evento fictício e construir um formulário de inscrição. 

As exigências da professora Suzana para a construção do formulário são:
- Utilizar o maior número possível de campos diferentes;
- O formulário deve ter:
Informações pessoais (nome, contato, data de nascimento, idade, etc.)
Preferências do participante (escolhas de cor, gostos, opções de participação, cidade, etc.)
Dados extras (senha, link, níveis, horários, períodos disponíveis, etc.)
Botões de ação (enviar).

Regras:
Organizar o formulário em seções com títulos.
Cada campo precisa ter um rótulo claro e identificadores.
Incluir validações básicas (campo obrigatório, limites de valores, tamanho máximo, etc.)
